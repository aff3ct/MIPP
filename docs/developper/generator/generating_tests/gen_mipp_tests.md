# gen_mipp_tests.py

`gen_mipp_tests.py` is a script that can be ran to generate every tests in 
`tests/src`. By default, it will generate tests for the C, CPP and Object layers 
of MIPP. 

It accepts the following CLI arguments:

- "c": only generate `tests/src/c_tests` 
- "cpp": only generate `tests/src/cpp_tests` 
- "obj": only generate `tests/src/obj_tests` 
- "all": default behavior, generates all of the tests.

The script only overwrites the test files if they have changed, to avoid 
needlesly recompiling them.

In the file, multiple functions are defined to make generation possible. These 
functions include: 

- `gen_test_type_guards` to add `#ifdef` conditions when calling test function 
  for specific datatypes on specific architectures, to ensure that only function 
  that **should actually be defined** on the architecture where MIPP is tested 
  are called (thus avoiding calling functions generated by `gen_missing_funcs`).
- `gen_func` to generate the body of a test function.
- and so on.

!!! info
    Variant of each function are written for `cast` and `cast_k` because they 
    are defined on a tuple of two datatypes instead of a single datatypes (i.e 
    `cast` and `cast_k` are defined on "to,from" types instead of single types).
