# gen_mipp_infos.py :


`gen_mipp_infos.py` is a script that can be ran to generate the `isas_support` and `func_support` sections of the doc. 
Instead of writing those sections by hand, they are generated using the informations contained in `helpers_headers/headers_def.py`,
`helpers_headers/generic_emu.py` and `simd_ext/*/*.py`.
